# Steam Deck / Steam Controller 2 — Current WoW Steam Input Setup

**Updated November 11, 2026.**

> **One universal layout only.** Download [Steam Deck / Steam Controller 2 WoW Layout](https://steaminputdb.com/config/3838058545).

The previous two-download workflow (separate World of Warcraft and Steam/Guide Button Chord configurations) is obsolete. **Do not install the old Guide Button Chord layout or copy the old two-layout instructions shown in earlier videos.**

## Installation

1. Add Battle.net to Steam as a non-Steam game if you are using Battle.net to launch WoW.
2. Open the [new universal layout](https://steaminputdb.com/config/3838058545).
3. Use **Preview / Apply** to open its Steam Input configuration and apply it to the World of Warcraft/Battle.net Steam shortcut that you actually launch.
4. Start WoW through the configured Steam shortcut. You do **not** need a second Guide Button configuration.
5. Install and enable [Mixolas Controller Bars](https://www.curseforge.com/wow/addons/mixolas-controller-bars) if you want the matching in-game action bar and keybinding setup. Back up native bindings before applying a preset.

## Free Mouse

Free Mouse is an **action set layer inside the same WoW layout**:

- **Hold D-pad Down** (175 ms long press) to enter the Free Mouse layer.
- The normal Always-On **right mouse click** is temporarily disabled, freeing mouse interaction.
- **LT** becomes **right mouse click** and **RT** becomes **left mouse click** while held.
- **Release D-pad Down** to return to the normal gameplay layer, including Always-On right mouse look.
- A normal **tap** of D-pad Down retains its original control.

The current universal layout also provides a mouse/ping binding family. An upcoming **Mixolas Controller Bars ping-support update** will be announced separately when released; do not assume an unreleased addon feature is part of an older downloadable build.
