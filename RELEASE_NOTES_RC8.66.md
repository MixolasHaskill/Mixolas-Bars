# Mixolas Bars v0.21.11 RC8.66 — Hardcore Beta

**Current public beta package** for World of Warcraft Classic Era / Hardcore by Mixolas HasKill.

**Download:** [MixolasBars_0.21.11_RC8.66_CurseForge_Hardcore_Beta_Lean.zip](https://raw.githubusercontent.com/MixolasHaskill/Mixolas-Bars/main/MixolasBars_0.21.11_RC8.66_CurseForge_Hardcore_Beta_Lean.zip)

**Target client:** World of Warcraft Classic Era / Hardcore — 1.15.9 (Interface 11509).

## Features

- Configurable action bars, modifier diamonds, attached/decorative frames, and Pet Bar.
- Controller-friendly SHIFT, CTRL, ALT, and combined-modifier keybinding organization.
- Customizable visuals, labels, positioning, and visibility.
- Built-in protected **MIXOLAS** Hardcore preset, with 59 Mixolas binding slots and 86 native WoW key mappings in the previously verified setup.
- Editable personal profiles, backup/restore, and portable settings import/export.
- Explicit confirmation before overwriting native World of Warcraft keybindings.

## Installation

1. Exit World of Warcraft.
2. Download the RC8.66 ZIP linked above.
3. Extract the `MixolasBars` folder into the appropriate `Interface/AddOns/` directory for your Classic Era / Hardcore installation.
4. Confirm the resulting path contains `MixolasBars/MixolasBars.toc`.
5. Enable the addon in the WoW AddOns list.
6. Back up existing SavedVariables and native WoW keybindings before applying the MIXOLAS preset.

## Important limitations

- Saved spell placements in Blizzard action slots and macro contents are **not** bundled with the preset.
- Camera views were observed applying on the author's tested installation, but cross-computer transfer has not been verified.
- Steam Input layouts are separate downloads; installing this addon does not apply Steam configurations.
- This is a **beta**, not a final stable release.
